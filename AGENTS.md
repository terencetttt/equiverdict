# GenLayer Project Instructions

This project is for a GenLayer vibecoding competition.

Official GenLayer Skills documentation:
https://skills.genlayer.com/

Before writing GenLayer code:

1. Read the official GenLayer documentation.
2. Follow the documented project structure and examples.
3. Do not invent APIs, commands, packages, or contract methods.
4. Use GenLayer Intelligent Contracts where appropriate.
5. Test all generated code.
6. Explain any documentation that cannot be accessed.
7. Prioritize a polished user experience and a reliable demo.
