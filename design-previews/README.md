# Design Previews for Freelance Dispute Resolver

This folder contains four static frontend design previews for the Freelance Dispute Resolver MVP. Each preview is intentionally static and uses realistic sample dispute data.

## Design options

1. `clean-professional`
   - A polished, corporate interface with a calm palette, clear structure, and precise information hierarchy.

2. `futuristic-web3`
   - A glassy, neon-infused interface that emphasizes modern Web3 credibility, status, and auditability.

3. `trust-and-justice`
   - A dignified design grounded in legal trust, with stately typography and symbolic justice cues.

4. `friendly-marketplace`
   - A warm, approachable marketplace experience that feels conversational and helpful.

## Files

Each design folder contains:
- `index.html` — a static preview page showing dashboard, dispute creation, evidence submission, and ruling/results screens.
- `styles.css` — theme styling for that design.

## Previewing

Open any `index.html` file in your browser to review the design. Each page is fully static and does not connect to wallets, contracts, or APIs.
