# Freelance Dispute Resolver Design Options

This document defines the four proposed UI design directions and the static preview structure for each.

## 1. Clean Professional
- Color palette: white, charcoal, slate blue, sky blue, soft grey.
- Typography: modern sans-serif with bold headings and clear body text.
- Navigation style: top nav with simple links and minimal icons.
- Buttons and form controls: crisp solid and ghost buttons, clean inputs with subtle borders.
- Dashboard layout: card-driven overview, status chips, case summary table.
- Dispute creation page: structured form, progress panel, clear section headings.
- Evidence submission page: evidence cards with summary, tags, and importance labels.
- Ruling/results page: verdict tile, confidence meter, explanation bullets.
- Mobile appearance: stacked cards, full-width forms, touch-friendly spacing.
- Accessibility considerations: high contrast, large text, clear labels, consistent focus states.

## 2. Futuristic Web3
- Color palette: dark navy, electric blue, teal, purple, neon gradients.
- Typography: futuristic sans or mono with a tech-forward feel.
- Navigation style: glassy top nav with glow accents, subtle animation.
- Buttons and form controls: glassmorphism, neon outlines, soft glows.
- Dashboard layout: metric cards, status chips, modular panels.
- Dispute creation page: compact multi-step layout, card-based fields, data chips.
- Evidence submission page: illuminated evidence blocks, metadata tags, strategic hierarchy.
- Ruling/results page: audit-style verdict card, ring confidence graphic, explanation chips.
- Mobile appearance: compact glass cards, bottom nav fallback, readable dark surfaces.
- Accessibility considerations: focus outlines, saturation-safe accent colors, readable text sizes.

## 3. Trust & Justice
- Color palette: navy, gold, cream, stone grey, burgundy.
- Typography: dignified serif headings paired with a neutral sans body.
- Navigation style: elegant top nav with subtle separators and badge indicators.
- Buttons and form controls: authoritative, contrast-rich buttons and neat form fields.
- Dashboard layout: structured list, timeline cards, strong visual hierarchy.
- Dispute creation page: formal sections, labeled inputs, clear guidance.
- Evidence submission page: card list with status badges, rationale prompts.
- Ruling/results page: verdict certificate style, summary blocks, rationale panel.
- Mobile appearance: stacked panels, large tap targets, simplified grid.
- Accessibility considerations: semantic structure, keyboard-friendly controls, clear color contrast.

## 4. Friendly Marketplace
- Color palette: warm peach, mint, navy, soft grey, coral.
- Typography: rounded sans-serif with friendly headings and approachable body text.
- Navigation style: friendly top nav with compact CTAs and subtle shadows.
- Buttons and form controls: pill-shaped buttons, spacious inputs, playful tags.
- Dashboard layout: marketplace-style cards with avatars, status chips, and friendly copy.
- Dispute creation page: conversational form layout, quick prompts, progress bar.
- Evidence submission page: drag-and-drop-inspired cards, insight labels, supportive helper text.
- Ruling/results page: approachable verdict card, next-step buttons, outcome summary.
- Mobile appearance: friendly stacked cards, bouncy button spacing, readable labels.
- Accessibility considerations: large touch targets, clear language, high contrast text and icons.
